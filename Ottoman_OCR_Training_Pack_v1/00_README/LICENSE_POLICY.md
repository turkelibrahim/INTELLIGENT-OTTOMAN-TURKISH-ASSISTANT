# Lisans Politikası

Bu paket kaynakları birbirine karıştırmadan lisans kökenini saklar.

- `CC BY-NC-SA`: araştırma/öğretim amaçlarında lisans şartlarına uyarak kullanılabilir; **NC** ticari kullanımı sınırlar, **SA** türev paylaşım koşulu getirir.
- `CC BY-NC`: ticari kullanım otomatik uygun değildir.
- `CC BY-SA`: atıf + aynı lisans koşulları uygulanır.
- `other / unclear`: açıkça izin doğrulanmadan train/release havuzuna alınmaz.

`10_sources/rights_manifest.csv` makine-okunur gate dosyasıdır. Ticari ürün hedefleniyorsa NC kaynaklar için ayrı izin veya ticari kullanıma uygun yeni veri gerekir.
